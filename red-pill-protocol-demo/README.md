# Red Pill Protocol Demo

Canonical Codex workspace for the Red Pill Protocol browser demo.

## Current vertical slice

- Four-player cyber-operator presentation
- Matrix-inspired digital Horde atmosphere with original Red Pill Protocol assets and terminology
- Fly / dash / teleport / melee / energy-shot control surface
- SoundCloud-powered in-game soundtrack through the official SoundCloud Widget API
- Authorized artist profile: https://soundcloud.com/almightysonoxo
- User-driven playback only; autoplay is disabled and no synthetic streaming is performed
- Music HUD with play/pause and SoundCloud attribution

Open `index.html` in a browser or serve this directory with any static web server.
